# Do It YourSelf (DIY) Platform - Trifecta3.0

![HTML](https://img.shields.io/badge/HTML-97.9%25-orange) ![CSS](https://img.shields.io/badge/CSS-1.6%25-blue) ![JavaScript](https://img.shields.io/badge/JavaScript-0.5%25-yellow) ![Status](https://img.shields.io/badge/Status-Active-brightgreen)

## 📋 Overview

**Trifecta3.0** is a comprehensive web application developed for **Techfusion at Dayanand Sagar** that revolutionizes how users access essential services. The DIY (Do It Yourself) Platform serves as a one-stop centralized hub, simplifying access to a diverse range of **legal, financial, and lifestyle services** all in one unified platform.

**Live Demo:** [https://doityourself-drab.vercel.app](https://doityourself-drab.vercel.app)

---

## 🎯 Purpose

The platform empowers users with easy-to-navigate access to crucial services across multiple domains, eliminating the need to jump between various websites and applications. Whether you need government documentation guidance, financial services, educational resources, or lifestyle conveniences, the DIY Platform consolidates everything into an intuitive, user-friendly interface.

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/CaptainAnant/Trifecta3.0.git
   cd Trifecta3.0
   ```

2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or deploy using any static hosting service (Vercel, GitHub Pages, Netlify, etc.)

### Deployment

The project is currently deployed on **Vercel**. To deploy your own version:

1. Fork the repository
2. Connect your GitHub account to Vercel
3. Create a new project and select this repository
4. Deploy with default settings
